Генератор IDEF0

Инструкция
Введите код IDEF0 на русском или английском. Команды:
- процесс/process ID "Название" — процесс (A0).
- вход/input ID "Название" -> процесс — вход (слева).
- управление/control ID "Название" -> процесс — управление (сверху, пунктир).
- выход/output процесс -> ID "Название" — выход (справа).
- выход/output процесс -> процесс — декомпозиция (пунктир).
- механизм/mechanism ID "Название" -> процесс — механизм (снизу, мелкий пунктир).
Пример:
процесс A0 "Производство"
вход I1 "Сырьё" -> A0
управление C1 "Инструкции" -> A0
выход A0 -> O1 "Продукт"
механизм M1 "Станки" -> A0
процесс A1 "Контроль"
вход I2 "Стандарты" -> A1
управление C2 "Нормативы" -> A1
выход A1 -> O2 "Отчёт"
механизм M2 "Инспекторы" -> A1
Нажмите "Сгенерировать" или выберите формат для сохранения графика.
