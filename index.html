Генератор диаграмм IDEF0

Инструкция: Введите код в формате IDEF0 на русском или английском. Команды:
- процесс или process ID "Название" — процесс (например, A0).
- вход или input ID "Название" -> процесс — вход (слева).
- управление или control ID "Название" -> процесс — управление (сверху, пунктир).
- выход или output процесс -> ID "Название" — выход (справа).
- выход или output процесс -> процесс — декомпозиция (пунктир).
- механизм или mechanism ID "Название" -> процесс — механизм (снизу, мелкий пунктир).
Пример:
процесс A0 "Производство"
вход I1 "Сырьё" -> A0
управление C1 "Инструкции" -> A0
выход A0 -> O1 "Продукт"
механизм M1 "Станки" -> A0
процесс A1 "Контроль"
вход I2 "Стандарты" -> A1
выход A0 -> A1
выход A1 -> O2 "Отчёт"
Нажмите "Сгенерировать" или "Экспорт SVG".
