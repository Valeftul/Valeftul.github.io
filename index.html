Генератор диаграмм IDEF0

Как использовать: Введите код в формате IDEF0 ниже. Пример синтаксиса:
process A0 "Основной процесс"
input I1 "Сырьё" -> A0
control C1 "Правила" -> A0
output A0 -> O1 "Продукт"
mechanism M1 "Оборудование" -> A0
Используйте process, input, control, output, mechanism. Нажмите "Сгенерировать" для отображения или "Экспорт SVG" для скачивания.
