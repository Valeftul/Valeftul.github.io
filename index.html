Генератор диаграмм IDEF0

Инструкция: Введите код в формате IDEF0. Используйте команды:
- process ID "Название" — процесс (например, A0).
- input ID "Название" -> процесс — вход (слева).
- control ID "Название" -> процесс — управление (сверху, пунктир).
- output процесс -> ID "Название" — выход (справа).
- output процесс -> процесс — связь между процессами.
- mechanism ID "Название" -> процесс — механизм (снизу, мелкий пунктир).
Пример:
process A0 "Производство"
input I1 "Сырьё" -> A0
control C1 "Инструкции" -> A0
output A0 -> O1 "Продукт"
mechanism M1 "Станки" -> A0
process A1 "Контроль"
output A0 -> A1
input I2 "Стандарты" -> A1
output A1 -> O2 "Отчёт"
Нажмите "Сгенерировать" или "Экспорт SVG".
